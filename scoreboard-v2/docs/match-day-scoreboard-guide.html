Scoreboard Match-Day Guide

Simple instructions for scorers, helpers, and adults supervising the scoreboard.

The scoreboard does not need internet to show scores. If Play Cricket or WiFi has problems, use the local manual scoring page or the admin recovery buttons.

Normal scoring

Use Play Cricket Scorer on the phone.

Connect it to BT-Scoreboard using Bluetooth.

If it goes wrong

Open the admin page and press Resend Current Score.

If starting again, press Reset to Zeros.

Manual scoring page

http://<pi-ip>/

Or on the Pi hotspot:

http://10.42.0.1/

Admin page

http://<pi-ip>/admin

Or on the Pi hotspot:

http://10.42.0.1/admin

Important for under-16 scorers

Do not change tokens, reboot the Pi, shut down the Pi, or change setup settings unless an adult asks you to.

If something is confusing, ask the captain, coach, or adult helper. The safest button during play is Resend Current Score.

1. Quick Match-Day Checklist

Before the match starts

  1. Turn on the scoreboard power.
  2. Wait about 60 seconds for the Raspberry Pi and Arduino to start.
  3. Open Play Cricket Scorer on the scoring phone.
  4. In Play Cricket Scorer, go to Settings - External Scoreboard - Generic.
  5. Connect to BT-Scoreboard.
  6. Ask an adult to open the admin page and press Reset to Zeros.
  7. Press All 8s Test only if checking the display before play. Then press Reset to Zeros again.
  8. Enter or confirm the starting score in Play Cricket Scorer.

During the match

  1. Score normally in Play Cricket Scorer.
  2. If the physical digits look wrong, open the admin page and press Resend Current Score.
  3. If Bluetooth stops working, use the manual scoring page until Bluetooth is fixed.
  4. If the board needs to be put back to all default zeros, press Reset to Zeros.

Do not panic if internet is down

Bluetooth scoring to the scoreboard can still work without internet. Online Play Cricket services may not update until internet returns, but the physical scoreboard can still be controlled.

2. Normal Scoring With Play Cricket Scorer

Use this when the phone and Bluetooth scoreboard connection are working.

  1. Open Play Cricket Scorer on the scoring phone.
  2. Open or create the match as normal.
  3. Go to Settings.
  4. Go to External Scoreboard.
  5. Choose Generic.
  6. Tap the scoreboard device named BT-Scoreboard.
  7. When it says connected, score the match as normal.

What should happen

Every score update in Play Cricket Scorer is sent by Bluetooth to the Pi. The Pi sends the score to the Arduino, and the Arduino updates the digits.

If the digits look wrong but Play Cricket is still working

  1. Open the admin page.
  2. Press Resend Current Score.
  3. Wait a few seconds.
  4. If the display is still wrong, ask an adult to press All 8s Test, then Reset to Zeros, then resend the score from Play Cricket.

3. If Play Cricket, Internet, or Bluetooth Has Problems

Problem What to do
Internet is down Keep scoring in Play Cricket if the app still works. The physical scoreboard can still update by Bluetooth. Use the admin or manual page from the Pi hotspot if needed.
Play Cricket Scorer will not update the board Open the admin page and press Resend Current Score. If that does not help, use the manual scoring page.
Bluetooth will not connect Use the manual scoring page until Bluetooth is fixed. Ask an adult to check the Bluetooth service later.
Digits are scrambled or missing Press Resend Current Score. If still wrong, press All 8s Test to check the display, then press Reset to Zeros.
Need to start fresh Press Reset to Zeros. Do not press Reboot or Shutdown unless an adult says so.

Manual scoring page

Use this page if Play Cricket or Bluetooth is not controlling the board.

  1. Connect a phone to the same WiFi as the scoreboard, or connect to the Pi hotspot DCC-Scoreboard.
  2. Open http://<pi-ip>/. If using the Pi hotspot, open http://10.42.0.1/.
  3. Enter the scorer token.
  4. Use the plus and minus buttons to change the score.
  5. Each change is sent to the physical scoreboard automatically.
  6. For a new innings or fresh start, press New Innings.

Scorer token

The scorer token is the password for the manual scoring page. Ask an adult for it. Do not share it outside the scoring team.

Write it on a private team sheet if needed, not on the public copy of this guide.

4. Admin Page: Recovery Buttons

The admin page is for recovery and setup. A younger scorer should normally only use it with an adult nearby.

Open:

http://<pi-ip>/admin

Or, on the Pi hotspot:

http://10.42.0.1/admin

Button Use it when...
Resend Current Score The scoreboard digits look wrong, but the score stored on the Pi is correct. This is the safest recovery during a match.
Reset to Zeros You are starting fresh or need the board back to default zeros.
Startup Sequence The board has just powered on and you want the Arduino to run its controlled startup again.
Clear Display You want all digits off. Use carefully during a match.
All 8s Test You are checking that every digit and segment can light. Do this before play, not during play unless needed.
Zero Walk An adult is testing each digit one at a time with a low-load zero.
Observe Mode An adult is filming the board to find the exact digit that fails.
Reboot Pi / Shutdown Pi Adult-only. Do not press these during play unless told to.

Admin token

The admin token unlocks recovery and setup controls. It should be held by an adult or lead scorer.

5. Adding Play Cricket API Token and Site ID

This is normally adult setup. It is not needed for Bluetooth scoring from Play Cricket Scorer, but it is useful for API sync and match lookup.

  1. Open the admin page: http://<pi-ip>/admin or http://10.42.0.1/admin.
  2. Enter the admin token.
  3. Find Play Cricket Live Sync.
  4. Under One-time setup, enter the Play Cricket Site ID.
  5. Enter the Play Cricket API Token.
  6. Press Save.
  7. Use Find Today's Matches to check the token and site ID are working.

Token safety

Do not put the API token in a public WhatsApp group or on a public printout. If a young scorer needs access, an adult should enter it for them.

Starting Play Cricket API sync

  1. Open the admin page.
  2. Press Find Today's Matches.
  3. Select the correct match.
  4. Optional: tick Dry Run first to check what it would send.
  5. Press Start Sync.
  6. If using Bluetooth scoring, you normally do not need API sync at the same time.

6. Using the Pi Hotspot When There Is No WiFi

The Pi can broadcast a local WiFi network so a phone can reach the manual scorer page and admin page without internet.

Hotspot details

WiFi name: DCC-Scoreboard

Manual scoring page: http://10.42.0.1/

Admin page: http://10.42.0.1/admin

Recommended phone setup

Phone Best use
Scorer phone Use Play Cricket Scorer with Bluetooth. Keep mobile data on if you need online Play Cricket services.
Second phone or adult phone Connect to DCC-Scoreboard WiFi and use admin/manual pages as the backup control.

If one phone must do everything

The scorer phone can briefly join DCC-Scoreboard WiFi to press a recovery button, then switch back if needed. Bluetooth scoring should continue separately, but using a second phone is cleaner.

7. Adult Setup: Hotspot and Services

This section is for adults or technical helpers.

Enable the Pi hotspot

  1. SSH into the Pi or use a keyboard and monitor.
  2. Go to the scoreboard folder: cd scoreboard/scoreboard-v2
  3. Run: HOTSPOT_PASSWORD='choose-a-password' bash setup_hotspot.sh
  4. On a phone, connect to WiFi DCC-Scoreboard.
  5. Open http://10.42.0.1/admin.

Set the scorer/admin tokens

The web server supports two tokens: one scorer token for the manual scoring page, and one admin token for adult recovery/setup actions. The Bluetooth service should use the admin token when it posts scores to the local server.

  1. Open /etc/systemd/system/scoreboard.service.
  2. Set ADMIN_TOKEN=adult-admin-token.
  3. Set SCORER_TOKEN=scorer-token.
  4. Open /etc/systemd/system/btscoreboard.service.
  5. Set the same ADMIN_TOKEN=adult-admin-token.
  6. Run sudo systemctl daemon-reload.
  7. Run sudo systemctl restart scoreboard btscoreboard.

Useful checks

Check Command or page
Node scoreboard server logs sudo journalctl -u scoreboard -f
Bluetooth service logs sudo journalctl -u btscoreboard -f
Arduino connected Admin page connection indicator should say Arduino connected.
Manual board check Admin page -> All 8s Test, then Reset to Zeros.

8. Final Fallback Plan

If something fails, work down this list. Do not change lots of things at once.

  1. If the displayed score is wrong, press Resend Current Score.
  2. If starting fresh, press Reset to Zeros.
  3. If Play Cricket Bluetooth is not updating the board, use the manual scoring page.
  4. If normal WiFi is unavailable, connect to the Pi hotspot DCC-Scoreboard.
  5. If the admin page cannot see the Arduino, ask an adult to check USB and restart services.
  6. If the display itself fails the All 8s Test, treat it as a wiring/power/hardware problem and ask an adult to inspect it.

Best recovery button during play

Resend Current Score is the safest first button. It does not reset the match; it just sends the known score again.

Do not do these unless an adult says so

  • Do not reboot the Pi during play.
  • Do not shut down the Pi during play.
  • Do not change saved API tokens during play.
  • Do not unplug wires or swap chips during play.
